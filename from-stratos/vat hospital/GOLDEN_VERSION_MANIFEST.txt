🚀 GOLDEN VERSION DEPLOYMENT
═════════════════════════════════════════════════════════════════════════════

INSTALLATION (5 Minutes):

1. Extract ZIP:
   unzip odoo-vet-hospital-19_0-GOLDEN-VERSION.zip

2. Copy to Odoo:
   cp -r vet_hospital /path/to/odoo/addons/
   cp -r vet_hospital_merck /path/to/odoo/addons/

3. Restart Odoo:
   sudo systemctl restart odoo

4. Update Apps List:
   Settings → Apps → Update Apps List

5. Install Modules:
   Search "Veterinary Hospital" → Install
   Search "Merck" → Install (optional)
